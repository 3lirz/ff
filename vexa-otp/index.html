SECURITY FIRST

مصمم كخدمة، مو مجرد صفحة.

  • Server-side secretsAccess Token وPhone Number ID لا يظهران بالمتصفح.
  • Hashed OTPيتم التحقق من hash بدلاً من حفظ الرمز كنص صريح.
  • Expiry + attemptsمدة صلاحية قصيرة وعدد محاولات محدود لكل challenge.
  • Rate limitingحدود حسب رقم الهاتف وIP للحد من الإساءة والتكاليف.
